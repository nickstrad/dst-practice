# Agent guide for docs/

The `docs/` folder holds documentation for people and agents. It holds no
code.

## Rules

- Read `docs/index.md` first.
- When you add a file to `docs/`, add one line for it to `docs/index.md`.
- Put learnings in `docs/knowledge/`, not in this folder. Follow the rules
  in `docs/knowledge/index.md`.
- Follow `docs/coding-style.md` when you write code.
- Write prose in active voice. The next section lists the rules.

## Writing rules

- Use active voice. Name the actor as the subject: "the retrier sleeps",
  not "a sleep is performed".
- Keep verbs as verbs. Write "decide", not "make a decision".
- Pick short plain words. Write "use", not "utilize" or "leverage".
- Cut padding. Drop "in order to", "it is important to note that", and
  empty adverbs like "simply" or "basically".
- Keep sentences short. Do not use em-dashes, parentheticals, or arrows in
  prose.
